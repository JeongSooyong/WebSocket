# 실시간 상담원 상태 보드 (WebSocket 토이 프로젝트)

WebSocket 개념(연결 유지, 이벤트 기반 통신, 브로드캐스트)을 직접 눈으로
확인해보기 위한 아주 작은 토이 프로젝트입니다. 별도 DB 없이 메모리에만
상태를 저장하고, `ws` 라이브러리로 실시간 브로드캐스트를 구현합니다.

## 실행 방법

```bash
npm install
npm start
```

`http://localhost:3000`을 **브라우저 탭 2~3개**로 열어보세요.

1. 각 탭에서 다른 이름으로 "입장"
2. 한 탭에서 "상담중" 버튼을 눌러보면
3. **다른 탭들의 목록이 새로고침 없이 바로 업데이트**되는 걸 확인할 수 있어요

## 코드에서 눈여겨볼 부분

- `server.js`의 `wss.on("connection", ...)` — 탭을 하나 열 때마다 이 콜백이
  새로 실행되고, 각 탭은 서로 다른 `socket`(연결)을 가짐
- `broadcastAgentList()` — `wss.clients.forEach(...)`로 연결된 모든 클라이언트에게
  현재 상태를 다시 뿌리는 부분. 이게 "실시간 반영"의 핵심 원리
- `public/index.html`의 `socket.addEventListener("message", ...)` — 서버가
  언제 보낼지 클라이언트는 미리 알 수 없고, 그냥 "받으면 그림을 다시 그린다"만
  약속해둠 (이벤트 기반 처리)

## 확장해보면 좋을 것

- 상담원이 "상담중"으로 바뀔 때 접속 시각을 같이 표시
- Express 라우트를 추가해서 REST API(`GET /api/agents`)로도 같은 데이터 조회
  가능하게 만들기 → REST와 WebSocket을 같이 쓰는 실무 패턴 연습
- 서버 재시작해도 상태가 안 사라지게 SQLite/PostgreSQL 연동 (URL 단축기
  프로젝트에서 썼던 `pg` 패턴 재사용 가능)
