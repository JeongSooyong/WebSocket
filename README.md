# 실시간 상담원 상태 보드 (WebSocket 토이 프로젝트)

WebSocket 개념(연결 유지, 이벤트 기반 통신, 브로드캐스트)을 직접 눈으로
확인해보기 위한 아주 작은 토이 프로젝트입니다.   
HTTP는 클라이언트의 요청이 있어야만 서버가 응답하는 단방향 통신인 반면, WebSocket은 연결을 유지한 상태에서 클라이언트와 서버가 실시간으로 데이터를 주고받는 양방향 통신입니다.

## 실행 방법

```bash
npm install
npm start
```

`http://localhost:3000`을 **브라우저 탭 2~3개**로 열어보세요.

1. 각 탭에서 다른 이름으로 "입장"
2. 한 탭에서 "상담중" 버튼을 눌러보면
3. **다른 탭들의 목록이 새로고침 없이 바로 업데이트**되는 걸 확인할 수 있어요

## 진행 상태  
현재 상담원 상태까지 완료
